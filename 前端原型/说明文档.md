# 学流智学 StudyFlow AI · 前端原型

一个「题库刷题 + 情感陪伴」的学习产品前端原型，纯静态 HTML / CSS / JavaScript，双击即可运行，无需构建、无需后端。

---

## 一、目录结构

```
studyflow-ai/
├── index.html              # 主页面：IDE 式题库工作台
├── quiz.html               # 做题页：全屏专注模式
├── 原型总览.html           # 原型图册，集中查看各页面截图与说明
├── assets/
│   └── xinyuehu.png        # AI 助手「心月狐」透明底立绘（可替换）
├── 原型截图/

│   ├── 02-心月狐陪伴对话与行动卡片.png
│   ├── 03-行动卡片跳转做题页.png
│   └── 04-窄屏自适应.png

```

## 二、如何运行

**方式一：直接打开**
双击 `index.html`，用 Chrome / Edge 打开即可。两个页面通过相对路径真实跳转。

**方式二：本地服务（推荐，避免个别浏览器的本地文件限制）**
```bash
cd studyflow-ai
python -m http.server 8777
# 浏览器访问 http://127.0.0.1:8777
```

## 三、页面与交互清单

### 页面 A · 主页面（index.html）

| 区域 | 说明 |
| --- | --- |
| 顶部导航 | 品牌、题库/教材/学习报告/学习小组、全局搜索、连续学习天数、头像 |
| 左侧工程树 | 仿 PyCharm 文件树：根节点 `studyflow-ai` → 科目文件夹（琥珀色）→ 章节子文件夹 → 题目文件（青色），带缩进参考线、折叠箭头、选中高亮；底部固定「外部库 / 临时文件和控制台」 |
| 右侧题库 | 面包屑、章节标题、学习进度条、筛选标签（全部/未作答/已作答/错题）、题目卡片列表 |
| 题目卡片 | 悬停轻微上浮 + 加深阴影；「查看解析」平滑展开解析面板；「开始做题」跳转做题页 |
| 状态栏 | 服务连接状态、学习计时、同步状态 |

**关键交互**
- 点科目文件夹：折叠 / 展开
- 点章节文件夹：折叠 / 展开 + 选中该章，右侧题目列表同步切换
- 点题目文件：直接进入该题的做题页
- 筛选标签、随机练习、继续上次练习

### 页面 B · 做题页（quiz.html）

- 全屏专注模式，无侧边栏
- 顶部：返回题库、第 X 题 / 共 N 题、分段进度、专注计时
- 题卡：题干、1/2/3/4 编号选项（避开 A/B/C/D 英文）、提交答案、跳过本题、需要提示
- 提交后：正确选项变青、错误选项变红，自动展开解析，按钮变为「下一题 / 完成练习」
- 键盘支持：数字 1–4 选择，回车提交

### 全局 · AI 情感助手「心月狐」

- 右下角悬浮球：角色头像 + 呼吸灯光环 + 在线状态点，点击展开/收起聊天窗
- 首次打开自动播放陪伴对话：
  - 用户：「我好焦虑，做不出来…」
  - 心月狐：深呼吸引导 + 情绪接纳 + 微行动建议
  - 附【微行动卡片】：「去做 2 道简单的极限题 · 约 6 分钟」，点击跳转做题页第 6 题
- 输入焦虑类关键词（焦虑 / 慌 / 做不出来 / 烦）会继续安抚并再次递出行动卡片
- 快捷问题：我好焦虑 / 给我鼓励 / 本章重点

## 四、数据与状态

- 题库数据写在前端 `QUESTIONS` 数组里，含 7 道题：数据结构 5 道 + 高数极限 2 道
- 答题结果写入浏览器 `localStorage`，键名 `studyflow_progress`，值为 `{题目id: "correct" | "wrong"}`
- 主页面读取该记录，显示已答对 / 已答错状态与章节正确率

## 五、二次开发提示

**替换 AI 角色**
把新的透明底 PNG 覆盖 `assets/xinyuehu.png` 即可，两处引用会自动生效（悬浮球 + 聊天窗头像）。建议 1024×1024、人物面部居中偏上。

**新增题目**
在 `index.html` 与 `quiz.html` 各自的 `QUESTIONS` 数组中追加同结构对象；主页面还需在 `TREE` 里补章节、在 `FILENAMES` 里补文件名。

**改主题色**
两个页面均以 CSS 变量控制，改 `:root` 里的 `--mint`、`--bg` 等即可实现换肤。
